\section{(準備)BosonとFermionのCoherent state}
このノートでは経路積分形式で使うためのcohenret状態とその性質についてまとめる。coherent状態を使う理由としては、後に見てわかる通り、場の演算子を微分・積分可能な数に置き換えるためである。

統計力学において、分配関数による物理量の計算を学んだことを覚えているだろうか？分配関数は一度積分を計算しておけば、あとは任意の物理量が微分(変分)によって計算が出来ることが利点であった。古典の場合は積分すれば良いのだが、量子の場合は分配関数の中身が演算子になっており、量子の演算子は一般に飛び飛びの値を取るため、そのままでは微分(変分)ができない。そこでcoherent状態を導入することで、演算子を微分・積分可能な数に置き換えることができるのである。(量子系を「古典系っぽく」扱うための方法だと思ってもらって良い。)

\subsection{ボゾンのcoherent状態}
場の生成・消滅演算子$\poi{a^{(\dagger)}_i}_{i=1}^N$が定義されている状態空間を考える。($[a_i, a_j^\dagger] = \delta_{ij}$が満たされているとする。)
この時コヒーレント状態はベクトル変数$\vec{\phi} = [\phi_1, \phi_2, \dots \phi_N]$($\phi_i$はc数(複素数))を用いて
\begin{eqnarray}
  \ket{\vec{\phi}} = \exp\Biglr{\sum_i \phi_i a_i^\dagger}\ket{0} = \prod_i \exp\Biglr{\phi_i a_i^\dagger}\ket{0}
\end{eqnarray}
と定義される。これは以下を満たす。
\begin{eqnarray}
  a_i \ket{\vec{\phi}} = \phi_i \ket{\vec{\phi}}, \quad \bra{\vec{\phi}} a_i^\dagger = \bra{\vec{\phi}} \phi_i^* \label{coherent_eigen}
\end{eqnarray}
よってこの状態の上では演算子はc数として振る舞う。


さらに、coherent状態に対する微分やnormについて計算すると
\begin{eqnarray}
  \frac{\p}{\p \phi_i} \ket{\vec{\phi}} = a^{\dagger}_i \ket{\vec{\phi}}, \quad \frac{\p}{\p \phi^*_i} \bra{\vec{\phi}} = \bra{\vec{\phi}} a_i, \quad \braket{\theta}{\phi} = \exp[\sum_i \theta_i^*\phi_i] \label{coh_norm}
\end{eqnarray}
また、このcoherent状態を用いて、今考えている状態空間全体を張ることが出来る。(完全性)
\begin{eqnarray}
  \hat{1} = \int \prod_i \Bigl(\frac{\mathrm{d}\phi_i^*\mathrm{d}\phi_i}{\pi}\Bigr) e^{-\sum_i |\phi_i|^2} \ket{\phi}\bra{\phi}
\end{eqnarray}

\begin{mdframed}[linewidth=1pt]
\textbf{練習問題(1):} 式(\ref{coherent_eigen})を示せ。\\
\textbf{練習問題(2):} 式(\ref{coh_norm})のnormについて示せ。\\
\textbf{練習問題(3):} 完全性について、まず
\begin{eqnarray}
  \hat{1} = \int \prod_i \Bigl(\frac{\mathrm{d}\phi_i^*\mathrm{d}\phi_i}{\pi}\Bigr) f(\{\phi_i, \phi_i^*\}_i) \ket{\phi}\bra{\phi}
\end{eqnarray}
として, $\hat{1}$が満たすべき性質$a \hat{1} = \hat{1}a, \quad a^\dagger \hat{1} = \hat{1}a^\dagger, \quad \bra{0}\hat{1}\ket{0} = 1$から$f(\{\phi_i, \phi_i^*\}_i)$を同定せよ。
\end{mdframed}


\subsection{Fermionのcoherent状態}
さてFermionについても同様にcoherent状態を定義したいが、同じようにc数で使って定義しようとすると、Fermionの反交換関係が反映されない。すなわち$c_i\ket{\phi} = \phi_i\ket{\phi}$とした場合に、$c_ic_j\ket{\phi} = \phi_i\phi_j\ket{\phi} = c_jc_i\ket{\phi}$となり、Fermionの反交換関係($c_ic_j = -c_jc_i$)と不整合である。
よって「反交換関係($\eta_i \eta_j = -\eta_j\eta_i$及び$\eta_i c_j = - c_j\eta_i$)を持つ数」を導入する必要がある。これがGrassmann数である。\footnote{ひょっとすると初めてGrassmann数(もしくはFermion)の交換関係を見た時に、「ベクトルの外積($\vec{A}\times\vec{B} = - \vec{B}\times\vec{A}$)みたいだな」と思った方もいるかもしれない。大正解である。Grassmann数は、ベクトル表現をすることが出来、積として外積(みんなが知っている３次元の外積を少し一般化したもの)の構造を入れたものになっている。ノートの最後に補足を書いておくので、興味がある人はどうぞ。}
経路積分に用いたいので、このGrassmann数の微分と積分を定義する必要がある。これは以下で定義しておくと経路積分で使う際に都合が良い。
\begin{eqnarray}
  \frac{\p}{\p\eta_i} \eta_j = \delta_{ij}, \quad \int d\eta_i 1 = 0, \quad \int d\eta_i \eta_j = \delta_{ij}\label{grass_ana}
\end{eqnarray}
この場合、Grassmann数を変数に持つ滑らかな関数$f(\eta)$の性質として、
\begin{eqnarray}
  f(\eta) = f(0) + \left.\frac{\p f}{\p\eta}\right|_{\eta=0}\eta = f(0) + f'(0)\eta
\end{eqnarray}
のように厳密に書けるという性質がある。反交換関係より$\eta_i^2 = 0$なので、$\eta_i$について1次までで展開できるのだ。特に使うものとして、expの形で
\begin{eqnarray}
  \exp(a \eta) = 1 + a\eta
\end{eqnarray}
となることを覚えておくと良いだろう。($a$はc数。)

さてGrassmann数と微分積分を含めたその演算を定義した。(足し算・引き算は特に定義しなかったが、ベクトルや通常のc数の足し算・引き算と同じように定義する。) これを用いて、Fermionのcoherent状態は、
\begin{eqnarray}
  \ket{\vec{\eta}} = \exp[-\sum_i\eta_i c^{\dagger}_i]\ket{0}
\end{eqnarray}
と定義する。このようにすれば
\begin{eqnarray}
  c_i \ket{\vec{\eta}} = \eta_i \ket{\vec{\eta}}, \quad \frac{\p}{\p\eta_i}\ket{\vec{\eta}} = -c^\dagger_i \ket{\vec{\eta}}
\end{eqnarray}
となる。また$\bar{\eta} = \eta^*$を用いて、
\begin{eqnarray}
  \bra{\vec{\eta}} = \bra{0}\exp[-\sum_i c_i \bar{\eta_i}] = \bra{0}\exp[\sum_i \bar{\eta_i} c_i] 
\end{eqnarray}
とすれば
\begin{eqnarray}
  \bra{\vec{\eta}}c^\dagger_i = \bra{\vec{\eta}} \bar{\eta_i}, \quad \frac{\p}{\p\bar{\eta}}\bra{\vec{\eta}} = \bra{\eta}c_i, \quad \braket{\eta}{\psi} = e^{\bar{\eta}\cdot\psi}
\end{eqnarray}
と書ける。ここで敢えて$\eta^*$と書かずに$\bar{\eta}$と書くのは、これらがGrassmann数の独立な元であることを強調する為であろう。

これらを用いて、Bosonの場合と同様に状態空間全体を張ることが出来る。
\begin{eqnarray}
  \hat{1} = \int \prod_i \Bigl(d\bar{\eta}_i d\eta_i\Bigr) e^{-\sum_i\bar{\eta_i}\eta_i}\ket{\vec{\eta}}\bra{\vec{\eta}}
\end{eqnarray}
\begin{mdframed}[linewidth=1pt]
\textbf{練習問題(4):} Fermionのcoherent状態の内積について確認せよ。\\
\textbf{練習問題(5):} Fermionのcoherent状態の完全性について、Bosonの場合と同様の手続きによって証明せよ。
\end{mdframed}

最後に経路積分で使うのでGrassmann数のGauss積分の公式を導いておこう。
\begin{eqnarray}
  \int d\bar{\eta}\int d\eta e^{-\bar{\eta}a\eta} &=& \int d\bar{\eta}\int d\eta (1 - \bar{\eta}a\eta)\nonumber\\
  &=& a\int d\bar{\eta} \bar{\eta}\int d\eta \eta = a
\end{eqnarray}
2行目から3行目の式変形に$\int d\eta \bar{\eta} = - \bar{\eta} \int d\eta$を用いた。(このようにGrassmann数は積分要素とも反交換関係が生じるので慣れが必要である)

さらに一般化して
\begin{eqnarray}
  \prod_i \Bigl(\int d\bar{\eta}_i \int d\eta_i\Bigr) e^{-\sum_{ij}\bar{\eta_i}A_{ij}\eta_j} = \det(A)
\end{eqnarray}
を得ることが出来る。

[証明]$\prod_{i=1}^n \Bigl(\int d\bar{\eta}_i \int d\eta_i\Bigr)$の積分の結果残るのは$\prod_{i=n}^1\eta_i\bar{\eta}_i$の係数である。$e^{-\sum_{ij}\bar{\eta_i}A_{ij}\eta_j} = \prod_{jk}(1 + \eta_k A_{jk}\bar{\eta}_j)$であるから、今求めたい係数は$j$同士,$k$同士で被らない$A_{jk}$の積の任意の組み合わせの和すなわち$1\sim n$を並べ替えたようなものの任意の並べ替えの和になる。さらにGrassmann数の性質により、$\prod_i\eta_i\bar{\eta}_i$の順番に並び替えようとした際に、並び替え$\sigma$に対して$\mathrm{sgn}(\sigma)$の符号が付くので、結果として
\begin{eqnarray}
  \prod_i \Bigl(\int d\bar{\eta}_i \int d\eta_i\Bigr) e^{-\sum_{ij}\bar{\eta_i}A_{ij}\eta_j} &=& \prod_i \Bigl(\int d\bar{\eta}_i \int d\eta_i\Bigr)\prod_{jk}(1 + \eta_k A_{jk}\bar{\eta}_j)\label{gauss_grass}\\
  &=& \prod_i \Bigl(\int d\bar{\eta}_i \int d\eta_i\Bigr)\sum_{\sigma} \prod_i \eta_\sigma(i) A_{i\sigma(i)} \bar{\eta}_{i}\\
  &=& \sum_{\sigma} \mathrm{sgn}(\sigma) \prod_i A_{i\sigma(i)} = \det(A)\label{grassmann_gauss}
\end{eqnarray}

さらにこのことから、Grassmann数の変数変換をした際の積分要素に出てくるJacobianも計算することが出来る。
というのも、$\vec{\eta'} = A \vec{\eta}$とすると式(\ref{gauss_grass})は
\begin{eqnarray}
  \Bigl(\int d\vec{\bar{\eta}} \int d\vec{\eta}\Bigr) e^{-\vec{\bar{\eta}}^T A \vec{\eta}} &=& \Bigl(\int d\vec{\bar{\eta}'} \int d\vec{\eta'}\Bigr) J^2(A) e^{-\vec{\bar{\eta}'}^TA^{-1} \vec{\eta'}} \\
  &=& J^2(A) \det(A^{-1}) = \det(A)\label{grassmann_jacobian}
\end{eqnarray}
よって$\vec{\eta} \rightarrow\vec{\eta'} = A \vec{\eta}$とする変数変換については$J(A) = \det(A)$となるヤコビアン考える事になる。これは通常の多変数の積分の逆数のファクターがかかる事になっている。これもGrassmann数の特殊性である(式(\ref{grass_ana})から、Grassmann数の積分はある種微分と同じ結果を返すために、むしろ微分としてヤコビアンを考えていると思っても良いかもしれない。)

\begin{mdframed}[linewidth=1pt]
\textbf{練習問題(6):} 上の証明の手順に沿って、n = 2の時($\eta_1, \eta_2$がある時)について、式(\ref{grassmann_gauss})と式(\ref{grassmann_jacobian})を実際に確認してみよ。\\
\textbf{練習問題(7):} 追加のGassmann数$\vec{\bar{\psi}}, \vec{\psi}$(ただし$\vec{\psi} = [\psi_1, \dots, \psi_n]^T$)を導入した時、以下を示せ。
\begin{eqnarray}
  \prod_i \Bigl(\int d\bar{\eta}_i \int d\eta_i\Bigr) \exp[-(\vec{\bar{\eta}}+\vec{\bar{\psi}})^T A (\vec{\eta} + \vec{\psi}) ] = \det(A)
\end{eqnarray}
\textbf{練習問題(8):} 上で証明した事を用いて、
\begin{eqnarray}
  \prod_i \Bigl(\int d\bar{\eta}_i \int d\eta_i\Bigr) \exp[-\vec{\bar{\eta}}^T A \vec{\eta} + \vec{\bar{\eta}}^T\cdot\vec{\psi} + \vec{\bar{\psi}}^T\cdot\vec{\eta}] = \det(A)\exp[\vec{\bar{\psi}}^T A^{-1} \vec{\psi}]\nonumber\\
  \label{moment}
\end{eqnarray}
となる事を示せ。(左辺の形を見て、「分配関数やモーメント母関数を似てるな」と思った方は良い嗅覚をお持ちである。)\\
よって式(\ref{moment})を用いて
\begin{eqnarray}
  \ev{\eta_i\bar{\eta}_j} &=& \left.\frac{\p}{\p\psi_j}\frac{\p}{\p\bar\psi_i}\right|_{\psi=0}\log\Bigl\{\prod_k \Bigl(\int d\bar{\eta}_k \int d\eta_k\Bigr) \exp\bigl[-\vec{\bar{\eta}}^T A \vec{\eta}+ \vec{\bar{\eta}}^T\cdot\vec{\psi} + \vec{\bar{\psi}}^T\cdot\vec{\eta}\bigr]\Bigr\}\nonumber\\
   &=& (A^{-1})_{ij}\label{Grassmann_Green}
\end{eqnarray}
\end{mdframed}

\section{分配関数の経路積分表示}

\subsection{コヒーレント状態によるトレース}
逆温度を$\beta=1/T$（$k_{\mathrm B}=1$）、化学ポテンシャルを$\mu$とし、
$\hat K=\hat H-\mu\hat N$とおく。大分配関数は$\hat{K}$の固有状態$\ket{\boldsymbol n}$($\hat{K}\ket{n} = \xi_n\ket{n}$)を用いて
\begin{equation}
  \Xi=\mathrm{Tr}\Bigl[e^{-\beta\hat K}\Bigr]
   =\sum_{n}\bra{n}e^{-\beta\hat K}\ket{n}
\end{equation}
と書ける。以下ではコヒーレント状態の変数を$\psi,\bar\psi$($\psi$は複数変数(ベクトル)の場合もある)と総称し、$d\bar\psi d\psi$を$d(\bar\psi,\psi)$と略して書く。これらはボゾンの系では複素数であり、フェルミオンの系ではGrassmann数である。
また、ファクター$\zeta$を導入し、ボゾンでは$\zeta=+1$、フェルミオンでは$\zeta=-1$とする。

占有数基底の和にコヒーレント状態の完全性を挿入すると、
\begin{align}
  Z &= \int d(\bar\psi,\psi)\,e^{-\bar\psi\cdot\psi} \sum_{n}\braket{n}{\psi}\bra{\psi}e^{-\beta\hat K}\ket{n} \\
  &= \int d(\bar\psi,\psi)\,e^{-\bar\psi\cdot\psi} \sum_{n}\braket{n}{\psi}\braket{\psi}{n}e^{-\beta\xi_n} \label{25}\\
  &= \int d(\bar\psi,\psi)\,e^{-\bar\psi\cdot\psi} \sum_{n}\braket{\zeta\psi}{n}\braket{n}{\psi}e^{-\beta\xi_n} \label{26}\\
  &= \int d(\bar\psi,\psi)\,e^{-\bar\psi\cdot\psi} \sum_{n}\braket{\zeta\psi}{n}\bra{n}e^{-\beta\hat K}\ket{\psi} \\
  &= \int d(\bar\psi,\psi) e^{-\bar\psi\cdot\psi} \bra{\zeta\psi}e^{-\beta\hat K}\ket{\psi}.
\end{align}
式(\ref{25})から式(\ref{26})の式変形には、状態$\ket{n}$はk個の粒子を含む状態とすると、$\braket{n}{\psi}\braket{\psi}{n} = \zeta^k\braket{\psi}{n}\braket{n}{\psi} = \braket{\zeta\psi}{n}\braket{n}{\psi}$である事を用いた。

\subsection{虚時間の離散化と連続極限}
$\beta$を$N$等分して$\Delta\tau=\beta/N$とし、$e^{-\beta\hat K}$を
$N$個の$e^{-\Delta\tau\hat K}$の積に分解する。隣り合う因子の間に完全性を挿入する。
$\hat K$を正規順序に並べ、その生成・消滅演算子をそれぞれ
$\bar\psi,\psi$に置き換えたものを$K(\bar\psi,\psi)$とすると、
\begin{align}
  Z &= \int d(\bar\psi_0,\psi_0) e^{-\bar\psi_0\cdot\psi_0} \bra{\zeta\psi_0}e^{-\beta\hat K}\ket{\psi_0} \\
  &= \prod_{i=0}^{N-1}\Bigl(\int d(\bar\psi_i,\psi_i) e^{-\bar\psi_i\cdot\psi_i}\Bigr)\bra{\zeta\psi_0}e^{-\tau\hat{K}}\ket{\psi_{N-1}}\dots\bra{\psi_1}e^{-\tau\hat{K}}\ket{\psi_0}
\end{align}
\begin{align}
  \bra{\psi_{j+1}}e^{-\Delta\tau\hat K}\ket{\psi_j}
  =\exp\Bigl[\bar\psi_{j+1}\cdot\psi_j-\Delta\tau K(\bar\psi_{j+1},\psi_j)\Bigr].
\end{align}
便宜上$\phi_N = \zeta\psi_0$とし、各完全性のガウス因子を取り込むと、
\begin{align}
  Z &= \prod_{i=0}^{N-1}\Bigl(\int d(\bar\psi_i,\psi_i) \exp\Bigl[-\Delta\tau\Bigl\{-\frac{\bar{\psi}_{i+1}-\bar{\psi}_i}{\Delta\tau}\psi_i + K(\bar{\psi}_{i+1}, \psi_i) \Bigr\}\Bigr]\Bigr)
\end{align}
$N\rightarrow\infty$の極限では、
\begin{align}
  Z &= \int\mathcal D[\bar\psi,\psi]\,e^{-S[\bar\psi,\psi]},\\
  S[\bar\psi,\psi]
    &= \int_0^\beta d\tau\,\Bigl[
       \bar\psi(\tau)\cdot\partial_\tau\psi(\tau)
       +K(\bar\psi(\tau+\Delta\tau),\psi(\tau))\Bigr].\label{imagtime_action}
\end{align}
ただし虚時間の境界条件として$\psi(\beta)=\zeta\psi(0)$、
$\bar\psi(\beta)=\zeta\bar\psi(0)$である。$N\rightarrow\infty$の極限で$\Delta\tau\rightarrow0$であるが、これが後々重要な役割をするので残しておく。

\subsection{松原振動数と自由系の分配関数}
境界条件に合わせて、虚時間の場を
\begin{align}
  \psi(\tau)&=\frac{1}{\sqrt{\beta}}\sum_{n\in\mathbb Z}\psi_n e^{-i\omega_n\tau},
  &\psi_n&=\frac{1}{\sqrt{\beta}}\int_0^\beta d\tau\,\psi(\tau)e^{i\omega_n\tau},\\
  \bar\psi(\tau)&=\frac{1}{\sqrt{\beta}}\sum_{n\in\mathbb Z}
       \bar\psi_n e^{i\omega_n\tau},
  &\omega_n&=
  \begin{cases}
    2\pi nT & (\text{ボゾン}),\\
    (2n+1)\pi T & (\text{フェルミオン})
  \end{cases}
\end{align}
と展開する。この$\omega_n$を松原振動数と呼ぶ。時刻のずれを残すと、
$\int_0^\beta d\tau\,\bar\psi(\tau+\Delta\tau)\cdot\psi(\tau)
=\sum_n e^{i\omega_n\Delta\tau}\bar\psi_n\cdot\psi_n$となる。一旦相互作用がない事を仮定すると、$K(\bar\psi, \psi) = \bar\psi_a K_{ab}\psi_b$の形で書ける\footnote{indexの$a,b$は略記している$\vec{\psi}(\tau)$の$\psi_a(\tau)$成分という意味である。松原振動数のindex $n$とは異なるので誤解しないように}ので、式(\ref{imagtime_action})に代入すると、
\begin{align}
  S[\bar\psi,\psi] = \sum_n \bar\psi_n (-i\omega_n + Ke^{i\omega_n\Delta\tau}) \psi_n 
\end{align}
ただし$K$は$K_{ab}$の行列表示したものである。

%\begin{comment}
$a$を1粒子Hamiltonianの固有状態のindexとすると、そのエネルギー固有値を$\varepsilon_a$、$\xi_a=\varepsilon_a-\mu$とすると、
$K(\bar\psi, \psi) = \sum_a \xi_a \bar\psi_a\psi_a$であり、作用は
\begin{equation}
  S=\sum_{a,n}\bar\psi_{an}(-i\omega_n+\xi_a)\psi_{an}\label{matsubara_action}
\end{equation}
と対角化される。ボゾンのガウス積分は行列式の逆数を与え、
フェルミオンのガウス積分は式(\ref{grassmann_gauss})の通り行列式を与える。
したがって$Z$は形式的に$\prod_n\det[\beta(-i\omega_n+\xi)]^{-\zeta}$と表せる。
ここで$\beta$が出てきたのは、$\prod_i\int d\bar\psi_i \int d\psi_i$を$\mathcal{D}[\bar\psi, \psi]$にした際に、積分測度をきちんとする必要があったのだ。(一度経路積分形式の導出を終える事を優先したため説明は一旦スキップした。)

つまり元々離散の場合に、離散のFourier変換をしておいて$\sum_i \bar\psi_{i+1}\psi_i \rightarrow \sum_n \bar\psi_{n}\psi_n e^{i\omega_n\Delta\tau}$として、離散版の作用$S_N$は
\begin{align}
  S_N = \sum_{n=1}^N \bar\psi_n(1 - e^{i\omega_n\Delta\tau}(1-\Delta\tau K))\psi_n \quad \rightarrow \quad  \sum_{n=1}^N \Delta\tau\bar\psi_n(-i\omega_n+Ke^{i\omega_n\Delta\tau})\psi_n
\end{align}
これが式(\ref{matsubara_action})と一致するには$\bar\psi' = \sqrt{\Delta\tau}\bar\psi$, $\psi' = \sqrt{\Delta\tau}\psi$として変数変換が必要になる
この際に$\prod_{n=1}^N\int d\bar\psi_n \int d\psi_n = \Bigl(\frac{\beta}{N}\Bigr)^{-\zeta N}\prod_{n=1}^N\int d\bar\psi'_n \int d\psi'_n$となるので、実は$\mathcal{D}[\bar\psi, \psi]$の中には$\mathrm{lim}_{N\rightarrow\infty}(\beta/N)^{-\zeta N}$が含まれており、この$\beta$が出てきていたのだ。

\subsection{練習：粒子数期待値}
この後に出てくるグリーン関数や解析接続の概念の良い例になるので、練習問題として、粒子数期待値を分配関数から計算してみよう。
index $a$の粒子数期待値は、便宜上化学ポテンシャルをindex $a$に依存する形で$\mu_a$と書き、
\begin{align}
  \ev{n_a} &= -\frac{1}{\beta}\left.\frac{\p}{\p\mu_a}\right|_{\mu_a=\mu}\mathrm{ln}Z[\beta, \{\mu_a\}] \\
  &= \prod_n\Bigl(\int\mathcal D[\bar\psi,\psi]\Bigr)\Bigl[\frac{1}{\beta}\int_0^\beta d\tau \bar\psi_a(\tau+\Delta\tau)\psi_a(\tau) e^{-S[\bar\psi, \psi]}\Bigr]/Z\\
  &= \frac{1}{\beta}\int_0^\beta d\tau\ev{\bar\psi_a(\tau+\Delta\tau)\psi_a(\tau)} = \ev{\bar\psi_a(\tau+\Delta\tau)\psi_a(\tau)}\\
  &= \frac{1}{\beta}\sum_n \ev{\bar{\psi}_{n,a}\psi_{n,a}}e^{i\omega_n\Delta\tau} = -\frac{\zeta}{\beta}\sum_n\Bigl(\frac{e^{i\omega_n\Delta\tau}}{i\omega_n - Ke^{i\omega_n\Delta\tau}}\Bigr)_{aa}\label{Matsubara_nev}
\end{align}
最後の等式について少し説明を追記する。もしも系がボゾンから構成されていれば、
%式(\ref{tauGreen})から式(\ref{Matsubara_nev})について少し説明を追記する。もしも系がボゾンから構成されていれば、
\begin{align}
  \ev{\bar\psi_{n,a}\psi_{n,a}} &= \prod_m(\int \mathcal{D}[\bar\psi_m, \psi_m]) \bar\psi_{n,a}\psi_{n,a} \exp[-\sum_m\bar\psi_m\cdot(-i\omega_m + \tilde{K}\cdot\psi_m]/\Xi\\
  &= -\frac{\p}{\p \tilde{K}_{aa}}\mathrm{ln}\Bigl[\int\mathcal{D}[\bar\psi_n, \psi_n]\exp[-\bar\psi_n\cdot(-i\omega_n + \tilde{K})\cdot\psi_n]\Bigr]\\
  &=-\frac{\p}{\p \tilde{K}_{aa}}\mathrm{ln}\Bigl[\det(-i\omega_n + \tilde{K})^{-\zeta}\Bigr]\\
  &= \Bigl((-i\omega_n + \tilde{K})^{-1}\Bigr)_{aa} = -\zeta\Bigl((i\omega_n - \tilde{K})^{-1}\Bigr)_{aa}\\
  &= -\zeta\Bigl((i\omega_n - Ke^{i\omega_n\Delta\tau})^{-1}\Bigr)_{aa}
\end{align}
またフェルミオンの場合は、式(\ref{Grassmann_Green})を用いて、同様に計算できる。

ひとまず、粒子数期待値が式(\ref{Matsubara_nev})の形で書けることは分かった。ところがこれは無限和を含んでいるので、$z = i\omega_n$に１次の極を持つ関数を導入し、複素積分を用いて計算する、という方針を取る。簡単のため$a$を$K$の固有状態のモードのindexということにすればそのような関数$F(z)$を導入して
\begin{align}
  -\frac{\zeta}{\beta}\sum_n\frac{e^{i\omega_n\Delta\tau}}{i\omega_n - \xi_ae^{i\omega_n\Delta\tau}} = -\frac{\zeta}{2\pi i\beta}\oint_{\gamma_0} dz \frac{e^{z\Delta\tau}}{z - \xi_ae^{z\Delta\tau}} F(z)
\end{align}
と書ける。ここで$\gamma_0$は$F(z)$の極を囲み、$1/(z-\xi_ae^{z\Delta\tau})$の極は囲わないような閉曲線である。周期的に極を持つようにするには$F(z)$は$F(z) \propto 1/(e^{\beta z}-\zeta)$とすれば良い。$e^{\beta (i\omega_n + \delta z)}-\zeta \simeq \zeta\beta\delta z$となるので、
\begin{align}
  \frac{1}{2\pi i}\oint_{\gamma_0} dz \frac{g(z)}{e^{\beta z}-\zeta} = \sum_n \frac{g(i\omega_n)}{\zeta\beta} = \sum_n \frac{\zeta g(i\omega_n)}{\beta} 
\end{align}
である。よってこれを用いると
\begin{align}
  &-\frac{\zeta}{\beta}\sum_n\frac{e^{i\omega_n\Delta\tau}}{i\omega_n - \xi_ae^{i\omega_n\Delta\tau}} = -\frac{1}{2\pi i}\oint_{\gamma_0} dz \frac{e^{z\Delta\tau}}{z - \xi_ae^{z\Delta\tau}} f_{\zeta}(z)\\
  &f_{\zeta}(z) = \frac{1}{e^{\beta z}-\zeta}
\end{align}
と書き直せる。ここで$f_{\zeta}(z)$はボゾンの場合はBose分布関数、フェルミオンの場合はFermi分布関数である。
ところで積分経路$\gamma_0$は$\xi_ae^{z\Delta\tau}$を囲ってさえなければ良いので、下図の$\gamma_1$と$\gamma_2$の経路の和($\oint_{\gamma_0}=\oint_{\gamma_1}+\oint_{\gamma_2}$)に書き直すことが出来る。
\begin{figure}[t]
  \centering
    \includegraphics[width=0.42\linewidth]{fig/contour.png}
    \includegraphics[width=0.42\linewidth]{fig/contour_boson.png}
    \caption{複素積分の経路\\
    左がFermion, 右がBoson(の経路の一部)}
    \label{fig:contour}
\end{figure}
さらに、無限遠の円弧の積分$\oint_{\gamma_4}$は、
\begin{align}
  &\oint_{\gamma_4} dz \frac{e^{z\Delta\tau}}{z - \xi_ae^{z\Delta\tau}} f_{\zeta}(z)\nonumber\\
  & = \lim_{r\rightarrow\infty}\int_0^{2\pi} d\theta \frac{e^{r e^{i\theta}\Delta\tau}}{r e^{i\theta} - \xi_ae^{r e^{i\theta}\Delta\tau}} \frac{1}{e^{\beta re^{i\theta}}-\zeta} i r e^{i\theta}
\end{align}
被積分関数について
\begin{align}
    &\lim_{r\rightarrow\infty}\int_0^{2\pi} d\theta \frac{e^{r e^{i\theta}\Delta\tau}}{r e^{i\theta} - \xi_ae^{r e^{i\theta}\Delta\tau}} \frac{i r e^{i\theta}}{e^{\beta re^{i\theta}}-\zeta}\nonumber\\
    &\rightarrow \begin{cases}
      -ir e^{i\theta}/(\xi_ae^{\beta r e^{i\theta}}) \rightarrow 0 & (\mathrm{Re}[re^{i\theta}]>0\quad(\mathrm{Re}[re^{i\theta}] = \infty))\\
      -ie^{r e^{i\theta}}/\zeta\rightarrow0 & (\mathrm{Re}[re^{i\theta}]<0\quad(\mathrm{Re}[re^{i\theta}] = -\infty))
    \end{cases}
\end{align}
であり、$\mathrm{Re}(re^{i\theta})=0$では有限の値だが、積分測度がゼロなので積分値には寄与しない(これが発散していたらデルタ関数と同じ理屈で積分値に寄与する)。よって、
\begin{align}
  &\oint_{\gamma_4} dz \frac{e^{z\Delta\tau}}{z - \xi_ae^{z\Delta\tau}} f_{\zeta}(z) = 0
\end{align}
となる。よって、この被積分関数について$\oint_{\gamma_0} = \oint_{\gamma_1} + \oint_{\gamma_2} - \oint_{\gamma_4} = -\oint_{\gamma_3}$であり、$\gamma_3$は、$z = \xi_ae^{z\Delta\tau}$の解を囲むような閉曲線である。よって
\begin{align}
  \ev{n_a} &= \frac{1}{2\pi i}\oint_{\gamma_3} dz \frac{e^{z\Delta\tau}}{z - \xi_ae^{z\Delta\tau}} f_{\zeta}(z) = \frac{1}{2\pi i}\oint_{\gamma_3} dz \frac{1}{z - \xi_a} f_{\zeta}(z)\\
  &= \frac{1}{2\pi i}\int_{-\infty}^{\infty} d\omega \Bigl(\frac{1}{\omega - \xi_a -i\delta} - \frac{1}{\omega - \xi_a +i\delta}\Bigr) f_{\zeta}(\omega)\label{real_axis}\\
  &= f_{\zeta}(\xi_a)
\end{align}
が得られる。ここで$G^A_{aa}(\omega) = (\omega - K - i \delta)^{-1}_{aa}=  1/(\omega - \xi_a - i \delta)$を先進グリーン関数, $G^R_{aa}(\omega) = (\omega - K + i \delta)^{-1}_{aa} = 1/(\omega - \xi_a + i \delta)$を遅延グリーン関数と呼ぶ。$G_A(\omega) = G_R^{\dagger}(\omega)$であるから、スペクトル関数$A_aa(\omega) = -\mathrm{Im}G^R_{aa}(\omega)/\pi$を用いて、
\begin{align}
  \ev{n_a} &= \int_{-\infty}^{\infty} d\omega A_{aa}(\omega) f_{\zeta}(\omega)
\end{align}
と書ける。相互作用のない時, $\delta\rightarrow0$で、$A_{aa}(\omega) = \delta(\omega -\xi_a)$となり、スペクトル関数は、粒子の実体としてのエネルギー値がどこにあるかを示すものになっている。
今回は練習問題として、知っている結果を経路積分から導くことが出来ることを確認した。このテクニックは今後でも使うので覚えておくこと。

ちなみに今回はFermionを仮定して、$\gamma_1\sim\gamma_3$について、図\ref{fig:contour}の左図のような経路を取った。しかし、Bosonの場合は松原振動数が$n=0$の場合に原点に極を持つので、このままの経路では$\gamma_3$にその極が含まれてしまう。
そこで、Bosonの場合は分布関数の性質から$\xi_a > 0$が保証されているので、図\ref{fig:contour}の右図のように経路を取る。この結果bosonの場合は式(\ref{real_axis})の積分範囲が$\int_{-\infty}^{\infty}\rightarrow \int_{+0}^{\infty}$と変更を受ける。


\section{応答関数と解析接続}
統計力学で、分配関数を微分して物理量の期待値を計算したことを思い出そう。
外場$F$が物理量$\hat X$に結合するとし、前節と同じく
$\hat K=\hat H-\mu\hat N$として、$\hat K(F)=\hat K+F\hat X$とおく。
このとき$Z(F)=\mathrm{Tr}\,e^{-\beta\hat K(F)}$より
\begin{equation}
  \ev{\hat X}_F=-\frac{1}{\beta}\frac{\partial\ln Z(F)}{\partial F}
\end{equation}
となる。例えば磁場とスピンの結合では、結合の符号を$\hat X$に含めればこの形で書ける。

\subsection{虚時間の応答関数}
経路積分形式では、外場を虚時間に依存する$F(\tau)$に一般化できる。
式(\ref{imagtime_action})の作用に外場との結合を加えると
\begin{align}
  Z[F]&=\int\mathcal D[\bar\psi,\psi]\,e^{-S_F[\bar\psi,\psi]},\\
  S_F[\bar\psi,\psi]&=S[\bar\psi,\psi]+\int_0^\beta d\tau\,F(\tau)X(\tau)
\end{align}
となる。例えば$\hat X$が一体演算子なら、離散表示で
$X(\tau_j)=\sum_{ab}\bar\psi_{j+1,a}X_{ab}\psi_{j,b}$のように書ける。また$X, F$をGrassmann数としても良い。(そうすれば"応答関数"としてFermionのグリーン関数が出る。)

ここでさらに一般化して、別の外場$F'(\tau')$ ($X'(\tau')F'(\tau')$の形でハミルトニアンに加わるとする)があった場合の$X(\tau)$の期待値は、
$\ln Z[F]$を変分すると
\begin{align}
  \ev{X(\tau)}_{F'} &= -\left.\frac{\delta}{\delta F(\tau)}\right|_{F=0}\ln Z[F, F'],\\
  \ev{X(\tau)}_{F'}-\ev{\hat X}_0
    &= \int_0^\beta d\tau'\,\chi^T_{XX'}(\tau,\tau')F'(\tau')
       +\mathcal O(F'^2),\\
  \chi_{XX}(\tau,\tau')
    &= -\left.\frac{\delta}
      {\delta F(\tau)}\frac{\delta}
      {\delta F'(\tau')}\right|_{F=F'=0}\ln Z[F, F']
      \label{response_source_derivative}
\end{align}
を得る。以降簡単のため$\ev{\hat X}_0=0$としておく。ここで、虚時間の連続極限を取る前の表式を思い出そう。
\begin{align}
  e^{-\bar\psi_i\cdot\psi_i}\bra{\psi_{i+1}}e^{-\Delta\tau \hat{K}}\ket{\psi_i} &= e^{-\bar\psi_i\cdot\psi_i}\bra{\psi_{i+1}}e^{-\Delta\tau K(\bar\psi_{i+1}, \psi_i)}\ket{\psi_i}\nonumber\\
  &\rightarrow \exp[-\Delta\tau\bigl(\bar\psi(\tau)\frac{\p}{\p\tau}\psi(\tau)+K(\tau)\bigr)]
\end{align}
のように$\tau$依存性を導入したので、一貫性を持つためには、外場の虚時間依存性も同様にして入るべきである。すなわち、
\begin{align}
  e^{-\bar\psi_i\cdot\psi_i}\bra{\psi_{i+1}}e^{-\Delta\tau \bigl(\hat{K}+\hat{X}F_i \bigr) }\ket{\psi_i} &= e^{-\bar\psi_i\cdot\psi_i}\bra{\psi_{i+1}}e^{-\Delta\tau \bigl(K(\bar\psi_{i+1}, \psi_i)+ X(\bar\psi_{i+1}, \psi_i)F_i\bigr)}\ket{\psi_i}\nonumber\\
  &\rightarrow \exp[-\Delta\tau\bigl(\bar\psi(\tau)\frac{\p}{\p\tau}\psi(\tau)+K(\tau) + X(\tau)F(\tau)\bigr)]
\end{align}
これが時間の大きい順に左から並んでいる状態を積分の形で表しているのが経路積分形式であった。故に、もしも$\tau > \tau'$であれば、
\begin{align}
  &\left.\frac{\delta}{\delta F(\tau)}\frac{\delta}{\delta F'(\tau')}\right|_{F=F'=0}\ln Z[F, F']\nonumber\\
      & = \left.\frac{\delta}{\delta F(\tau)}\right|_{F=F'=0}\frac{1}{Z}\prod_i\Bigl(\int d\bar\psi_i d\psi_ie^{-\bar\psi_i\psi_i}\Bigr)  \bra{\zeta\psi_0}\dots\ket{\psi_{i+1}} X(\tau=\tau_i)\bra{\psi_{i+1}}e^{-\Delta\tau K(\bar\psi_{i+1}, \psi_i)}\ket{\psi_i} \dots\nonumber\\
      &= \frac{1}{Z}\prod_i\Bigl(\int d\bar\psi_i d\psi_ie^{-\bar\psi_i\psi_i}\Bigr) \bra{\zeta\psi_0}\dots\ket{\psi_{j+1}}X(\tau=\tau_j) \dots X(\tau'=\tau_i)\dots\ket{\psi_0}\\
      &= \ev{X(\tau)X'(\tau')} 
\end{align}
逆に$\tau<\tau'$の場合は、例えばもし$F, F'$がGrassmann数ならば、$\delta/\delta F(\tau)$と$X(\tau')$を交換する際に$\zeta_X$が出てくるので、
\begin{align}
  &\left.\frac{\delta}{\delta F(\tau)}\frac{\delta}{\delta F'(\tau')}\right|_{F=F'=0}\ln Z[F, F'] = \zeta_X \ev{X'(\tau')X(\tau)}
\end{align}
となる。よってこれらをまとめて、
\begin{align}
  \chi_{XX'}(\tau,\tau') = \begin{cases}
    -\ev{X(\tau)X'(\tau')} & (\tau > \tau')\\
    -\zeta_X \ev{X'(\tau')X(\tau)} & (\tau < \tau')
  \end{cases}\label{tau_order}
\end{align}
と書ける。
さて、ここまでcoherent状態を用いて経路積分形式で書いてきたが、ここで一旦解析接続が出来る事の確認のために、多体ハミルトニアンの固有状態を用いた表式に戻ろう。つまり$\mathcal{O}(\tau)\rightarrow \hat{O}$として再び演算子に戻せば良いので、
\begin{align}
  \ev{X(\tau)X'(\tau')}_0
  &=\frac{1}{Z_0}\mathrm{Tr}\Bigl[
     e^{-(\beta-\tau)\hat K}\hat X'
     e^{-(\tau-\tau')\hat K}\hat X' e^{-\tau'\hat K}\Bigr]\\
  &=\frac{1}{Z_0}\mathrm{Tr}\Bigl[
     e^{-\beta\hat K}\hat X(\tau-\tau')\hat X'\Bigr] = \ev{X(\tau-\tau')X'(0)}_0,\label{tau_trace}\\
  \hat X(\tau)&=e^{\tau\hat K}\hat X e^{-\tau\hat K}.
\end{align}
最後の式ではトレースの巡回性を用いた。したがって平衡状態では、相関関数は虚時間の差だけに依存する。(虚時間の並進対称性がある。)
以降の視認性のために、観測する演算子を$\hat{X} \rightarrow \hat A$、外場と結合する演算子を$\hat{X'} \rightarrow \hat B$とする。トレースの形にすると、応答関数の形がわかりやすい。というのも、トレースの巡回性から $<0\tau<\beta$として
$\ev{\hat A(\tau)\hat B}_0 = \zeta_A \ev{\hat A(\tau-\beta)\hat B}_0 = \zeta_A \ev{\hat B\hat A(\tau-\beta)}_0$となるので、
$\chi_{AB}(\tau-\beta)=\zeta_X\chi_{AB}(\tau) \quad (0<\tau<\beta)$となり、式(\ref{tau_order})が導かれる。
よって$0\leq\tau<\beta$について$\zeta_X=+1$なら周期的、$\zeta_X=-1$なら反周期的である。

\subsection{虚時間相関関数のLehmann表示}
$\hat K\ket{m}=E_m\ket{m}$とし、$p_m=e^{-\beta E_m}/Z$とおく。
$A_{m\ell}=\bra m\hat A\ket\ell$、$B_{\ell m}=\bra\ell\hat B\ket m$と書くと、
式(\ref{tau_order}), 式(\ref{tau_trace})に完全性($\hat{1} = \sum_n\ket{n}\bra{n}$)を挿入して
\begin{align}
  \chi^T_{AB}(\tau)
  =-\sum_{m,\ell} A_{m\ell}B_{\ell m}e^{\tau(E_m-E_\ell)}
     \Bigl[\theta(\tau)p_m+\zeta_X\theta(-\tau)p_\ell\Bigr]
\end{align}
を得る。このように、相関関数を固有状態の和で表したものをLehmann表示と呼ぶ。

松原振動数$\omega_n$は$e^{i\omega_n\beta}=\zeta_X$を満たすものを選ぶ。
これにより$e^{i\omega_n\tau}\chi^T_{AB}(\tau)$は$\beta$周期/反周期になるので、2倍の周期でFourier変換して半分にすればよく、
\begin{align}
  \chi^T_{AB}(i\omega_n)
    &=\frac{1}{2}\int_{-\beta}^{\beta} d\tau\,
        e^{i\omega_n\tau}\chi^T_{AB}(\tau)
     =\int_0^\beta d\tau\,e^{i\omega_n\tau}\chi^T_{AB}(\tau)\\
    &=-\sum_{m,\ell}p_m A_{m\ell}B_{\ell m}
        \int_0^\beta d\tau\,e^{(i\omega_n+E_m-E_\ell)\tau}.
    \label{response_matsubara_integral}
\end{align}
$p_m e^{i\omega_n\beta+\beta(E_m-E_\ell)}
=\zeta_X p_\ell$より
\begin{equation}
  \chi^T_{AB}(i\omega_n)
    =\sum_{m,\ell}
       \frac{(p_m-\zeta_X p_\ell) A_{m\ell}B_{\ell m}}
            {i\omega_n+E_m-E_\ell}.
    \label{response_matsubara_lehmann}
\end{equation}
ボゾン型の$\omega_n=0$で$E_m=E_\ell$の項は、式(\ref{response_matsubara_integral})から
直接$-\beta p_m A_{m\ell}B_{\ell m}$と評価する。

\subsection{実時間の線形応答}
時刻$t_0$に平衡状態$\hat\rho_0=e^{-\beta\hat K}/Z$から出発し、
外場$F(t)$を加えたときの$\ev{\hat A(t)}$を考えよう。
(解析接続のための)対応関係を確認するため、$\hat{A}, \hat{B}$は$\hat{c}^\dagger_{n} O_{nm}\hat{c}_m$のような形で書けると仮定し\footnote{この仮定をした場合、自動的に$\zeta_A = \zeta_B = 1$となる。}、時間発展の生成子を$\hat K$に書き換える。（totalの粒子数を保存する演算子の
$\hat{K}$による時間発展は、$\hat H$で時間発展させた場合と同じになる）。
まず$F(t)$が$\hat{B}$と結合している外場とする。簡単のため$\hbar=1$として、時間発展演算子と相互作用表示は
\begin{align}
  \hat U(t, t_0)&=\mathcal T_>\exp\Bigl[-i\int_{t_0}^{t}dt'\,
                       \bigl(\hat K+\hat B F(t')\bigr)\Bigr],\\
  \hat U_0(t, t_0)&=e^{-i\hat K(t-t_0)} = \hat U_0(t - t_0),\quad
  \hat U_I(t, t_0)=\hat U_0^\dagger(t, t_0)\hat U(t, t_0),
\end{align}
と書ける。ただし$\mathcal T>$は(実)時間順序積を表す。
外場の一次まで展開すると、演算子の相互作用表示$\hat A^I(t)=\hat U_0^\dagger(t-t_0)\hat A\hat U_0(t-t_0)$の記法を用いて、
\begin{align}
  \hat U_I(t) &= \hat{U}_0^{\dagger}(t)\Bigl[U_0(t) -i \mathcal{T}_>\int_{t_0}^{t} dt'\hat{U}_0(t-t')\hat{B} F(t') \hat{U}_0(t'-t_0) +  +\mathcal O(F^2) \Bigr]\\
        &=\hat 1-i\int_{t_0}^{t}dt'\,\hat B^I(t')F(t')+\mathcal O(F^2)
\end{align}
となる。これを
$\ev{\hat A(t)}_F=\mathrm{Tr}[\hat U_I^\dagger(t)\hat A^I(t)\hat U_I(t)\hat\rho_0]$
に代入すると
\begin{align}
  \delta\ev{\hat A(t)}
   &= -i\int_{t_0}^{t}dt'\,
       \ev{[\hat A_0(t),\hat B_0(t')]}_0F(t')+\mathcal O(F^2)\\
   &=\int_{-\infty}^{\infty} dt'\,\chi^R_{AB}(t-t')F(t')+\mathcal O(F^2)
\end{align}
を得る。ここでは$t'<t_0$で$F(t')=0$とした。一般に遅延応答関数は
\begin{align}
  \chi^R_{AB}(t-t')
    &=-i\theta(t-t')\ev{[\hat A_0(t),\hat B_0(t')]_{\zeta_X}}_0,\\
  [\hat A,\hat B]_{\zeta_X}&=\hat A\hat B-\zeta_X\hat B\hat A
\end{align}
と書ける。
パリティ奇の演算子に対しては、形式的なGrassmann外場を$\hat B$の右に置く。一次の展開で$\hat B_0(t')F(t')\hat A_0(t)$の$F(t')$を右に移すと負号が付くため、交換子は反交換子になる。\footnote{この場合$\hat{B}$は全粒子数$\hat{N}$と交換しないので、相互作用描像の時間発展を$\hat{H}$で行う必要がある}

\subsection{遅延応答関数のLehmann表示と解析接続}
虚時間の場合と同様に固有状態を挿入し、積の順番を逆にした項で$m,\ell$を入れ替えると、
\begin{equation}
  \ev{[\hat A_0(t),\hat B_0(t')]_{\zeta_X}}_0
    =\sum_{m,\ell}(p_m-\zeta_X p_\ell)A_{m\ell}B_{\ell m}
       e^{i(E_m-E_\ell)(t-t')}
\end{equation}
となる。Fourier変換の規約を$g(\omega)=\int_{-\infty}^{\infty}dt\,e^{i\omega t}g(t)$とすると、
線形応答は$\delta\ev{\hat A}(\omega)=\chi^R_{AB}(\omega)F(\omega)$となる。

$\epsilon>0$として$-i\int_0^\infty dt\,e^{ixt-\epsilon t}=1/(x+i\epsilon)$である。
また、$\theta(t)$は
\begin{equation}
  \theta(t)=\lim_{\epsilon\rightarrow0}\int_{-\infty}^{\infty}
    \frac{d\omega'}{2\pi}\frac{i e^{-i\omega't}}{\omega'+i\epsilon}
    \qquad (t\ne 0)
\end{equation}
とも書ける。この積分では$t>0$で下半平面に経路を閉じ、
$t<0$では上半平面に閉じる。
よって実時間のLehmann表示は
\begin{equation}
  \chi^R_{AB}(\omega)=\sum_{m,\ell}
    \frac{(p_m-\zeta_X p_\ell)A_{m\ell}B_{\ell m}}
         {\omega+E_m-E_\ell+i0^+}.
  \label{response_retarded_lehmann}
\end{equation}

式(\ref{response_matsubara_lehmann})と式(\ref{response_retarded_lehmann})を見比べよう。
複素変数$z$の関数
\begin{equation}
  \chi_{AB}(z)=\sum_{m,\ell}
     \frac{(p_m-\zeta_X p_\ell)A_{m\ell}B_{\ell m}}{z+E_m-E_\ell}
\end{equation}
を考えると、虚時間の相関関数はその虚軸上の値であり、
遅延応答関数は上半平面から実軸に近づけた境界値である。
したがって虚時間の相関関数を計算したあと、
$i\omega_n\longrightarrow\omega+i0^+$と解析接続することで遅延応答関数が求まる。
ただし、先に求めたボゾン型の$\omega_n=0$にだけ現れる等エネルギー項は、
虚時間に依存しない静的な寄与である。遅延応答関数では、
この項の係数$p_m-p_\ell$がゼロになる。

\section{電場応答と量子幾何}
\subsection{velocity gaugeとlength gauge}
まずは高校の物理でも出てくるような電場の入ったハミルトニアンからスタートしよう。
\begin{align}
  \hat{H}_{E}(t) = \frac{\hat{p}^2}{2m} + V(\hat{r}) - q \vec{E}(t)\cdot\vec{\hat{r}}
\end{align}
物性物理ではこの形で電場が入るゲージの取り方をlength gauge(長さゲージ)と呼ぶ。このゲージの取り方をしている状態に対して、ゲージ変換$\ket{\tilde{\psi}} = e^{i\chi(\hat{r}, t)}\ket{\psi}$を加えた状態が従うハミルトニアンを考えてみよう。すなわち、
\begin{align}
  i\frac{d}{dt}\ket{\tilde{\psi}} &= e^{i\chi(\hat{r}, t)}\Bigl(i\frac{d}{dt} - \frac{d\chi}{dt}\Bigr)\ket{\psi} = \Bigl(e^{i\chi(\hat{r}, t)}\hat{H}_E(t)e^{-i\chi(\hat{r}, t)} - \frac{d\chi}{dt}\Bigr)\ket{\tilde{\psi}}\\
  &= \hat{\tilde{H}}(t) \ket{\tilde{\psi}},\\
  \Rightarrow & \hat{\tilde{H}}(t) = e^{i\chi(\hat{r}, t)}\hat{H}_E(t)e^{-i\chi(\hat{r}, t)} - \frac{d\chi}{dt}.
\end{align}
ところで、もし結晶の話を考えたい場合、なんとなくハミルトニアンに結晶の並進対称性が欲しくなるであろう。しかしlength gaugeの$q \vec{E}(t)\cdot\vec{\hat{r}}$はそのような対称性を有していない。よって、$\chi(\hat{r}, t)$をうまく設定することでこの項を消し、並進対称性を復活させる事を試みたい。$\chi(\hat{r}, t) = -q[\int_0^t dt' \vec{E}(t')]\cdot \vec{\hat{r}} = q \vec{A}(t)\cdot \vec{\hat{r}}$とすれば、
\begin{align}
    \hat{\tilde{H}}(t) = e^{i\chi(\hat{r}, t)}\Bigl(\frac{\hat{p}^2}{2m} + V(\hat{r})\Bigr)e^{-i\chi(\hat{r}, t)} = \frac{(\hat{p} - q \vec{A}(t))^2}{2m} + V(\hat{r})
\end{align}
となり、これは並進対称性を持つ。このゲージの取り方を(ベクトルポテンシャルが運動量と結合している事から)velocity gauge(速さゲージ)と呼ぶ。

\subsection{結晶中の電磁場}
\subsubsection{強束縛模型とBloch Hamiltonian}
ポテンシャル項がある離散対称性を持っている場合、すなわち$\vec{R} = \sum_{i = 1}^d n_i \vec{a}_i$(ただし$n_i$は整数。)として、$V(\hat{r}) = V(\hat{r} - \vec{R})\quad (\forall n_i)$と書ける場合を考える。離散並進演算子$\hat{T}_R\ket{r} = \ket{r+R}$, $\hat{T}_R \hat{r} = (\hat{r}-\vec{R})\hat{T}_R$, $[\hat{T}_R, \hat{p}]=0$を導入すると、$[\hat{T}_R,\hat{H}] = 0$が成り立つので
\begin{align}
  &\hat{H}\ket{\psi_n} = E_n\ket{\psi_n}, \quad [\hat{T}_R,\hat{H}] = 0\\
  &\Rightarrow \hat{T}_R\hat{H}\ket{\psi_n} = \hat{T}_RE_n\ket{\psi_n} = E_n\hat{T}_R\ket{\psi_n} = \hat{H}\hat{T}_R\ket{\psi_n}\label{same_eig}
\end{align}
式(\ref{same_eig})より$\hat{T}_R\ket{\psi_n} \propto \ket{\psi_n}$である事がわかる。さらに、$\hat{T}_R*\hat{T}_{R'} = \hat{T}_{R+R'}$より$\hat{T}_R\ket{\psi_n} = e^{ikR} \ket{\psi_n}$と書けると同定できる。ここで$\ket{\psi_n}$が$\hat{T}_R$について固有値$e^{ikR}$の固有状態である事を明示するために以降では$\ket{\psi_{nk}}$と表記する。
またこの性質より、
\begin{align}
  \braket{r-R}{\psi_{nk}} = \bra{r}\hat{T}_R\ket{\psi_{nk}} = e^{ikR}\braket{r}{\psi_{nk}} \Leftrightarrow \psi_{nk}(r-R) = e^{ikR}\psi_{nk}(r) 
\end{align}
が満たされる。
ここでWannier状態$\ket{w_n(R)} = \sum_k e^{-ikR}\ket{\psi_n(k)}/\sqrt{N}$を導入すると、
\begin{align}
  \braket{r}{w_n(R)} &= \frac{1}{\sqrt{N}}\int dk e^{-ikR} \braket{r}{\psi_{nk}} = \frac{1}{\sqrt{N}}\int dk \braket{r-R}{\psi_{nk}} = \braket{r-R}{w_n(0)}\\
  & = \frac{1}{\sqrt{N}}\int dk e^{-ik(R-R')}\braket{r-R'}{\psi_{nk}} = \braket{r-R'}{w_n(R-R')}
\end{align}
が成立する。この状態でのハミルトニアンの表現を考えてみよう。すなわち、
\begin{align}
  \hat{H} &= \sum_{mn}\sum_{R,R'}\ket{w_m(R)}\bra{w_m(R)}\hat{H}\ket{w_n(R')}\bra{w_n(R')}\\
  &= \sum_{mn}\sum_{R,R'}\ket{w_m(R)}t_{mn}(R, R')\bra{w_n(R')}
\end{align}
の$t_{mn}(R,R')$を考えていきたい。この表現での(特に$|R-R'|$が小さいところで打ち切った)ハミルトニアンをtight-binding模型(強束縛模型)と呼ぶ。
ポテンシャル項の寄与について、
\begin{align}
  \bra{w_m(R)}V(\hat{r})\ket{w_n(R')} &= \int dr \braket{w_m(R)}{r}V(r)\braket{r}{w_n(R')}\\
  &=\int dr \braket{w_m(0)}{r-R}V(r)\braket{r-R}{w_n(R'-R)}\\
  &=\int dr \braket{w_m(0)}{r-R}V(r-R)\braket{r-R}{w_n(R'-R)}\\
  &=\int dr \braket{w_m(0)}{r}V(r)\braket{r}{w_n(R'-R)}
\end{align}
と書けるので、これは$R'-R$に依存する。$\hat{p}^2$の項についても並進対称性があるので同様に$R'-R$に依存する。離散並進対称性がある系においては$t_{mn}(R,R') = t_{mn}(R'-R)$と書ける。

さて、この表現を元々の$\ket{\psi_{nk}}$の表現に変換すると、$\ket{w_n(R)} = \sum_k e^{-ikR}\ket{\psi_{nk}}/\sqrt{N}$であるから、
\begin{align}
  \hat{H} &= \sum_{mn}\sum_{R,R'}\ket{w_m(R)}t_{mn}(R, R')\bra{w_n(R')}\\
  &= \sum_{mn}\sum_{k,k'}\ket{\psi_{mk}}\bra{\psi_{nk'}}\frac{1}{N}\sum_{R,R'}t_{mn}(R'- R)e^{i(k'R'-kR)}\\
   &= \sum_{mn}\sum_{k}\ket{\psi_{mk}}\bra{\psi_{nk}}\frac{1}{N}\sum_{R,R'}t_{mn}(R'- R)e^{ik(R'-R)} = \sum_{mn}\sum_{k}\ket{\psi_{mk}}\bra{\psi_{nk}} H_{mn}(k).
\end{align}
2行目から3行目の式変形には$[\hat{T}_R,\hat{H}]=0$(すなわち$k$について対角)である事を用いた。$H_{mn}(k)$の表現でのハミルトニアンをBloch Hamiltonianと呼ぶ。
