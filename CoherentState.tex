\section{(準備)BosonとFermionのCoherent state}
このノートでは経路積分形式で使うためのcohenret状態とその性質についてまとめる。coherent状態を使う理由としては、後に見てわかる通り、場の演算子を微分・積分可能な数に置き換えるためである。

統計力学において、分配関数による物理量の計算を学んだことを覚えているだろうか？分配関数は一度積分を計算しておけば、あとは任意の物理量が微分(変分)によって計算が出来ることが利点であった。古典の場合は積分すれば良いのだが、量子の場合は分配関数の中身が演算子になっており、量子の演算子は一般に飛び飛びの値を取るため、そのままでは微分(変分)ができない。そこでcoherent状態を導入することで、演算子を微分・積分可能な数に置き換えることができるのである。(量子系を「古典系っぽく」扱うための方法だと思ってもらって良い。)

\subsection{ボゾンのcoherent状態}
場の生成・消滅演算子$\poi{a^{(\dagger)}_i}_{i=1}^N$が定義されている状態空間を考える。($[a_i, a_j^\dagger] = \delta_{ij}$が満たされているとする。)
この時コヒーレント状態はベクトル変数$\vec{\phi} = [\phi_1, \phi_2, \dots \phi_N]$($\phi_i$はc数(複素数))を用いて
\begin{eqnarray}
  \ket{\vec{\phi}} = \exp\Biglr{\sum_i \phi_i a_i^\dagger}\ket{0} = \prod_i \exp\Biglr{\phi_i a_i^\dagger}\ket{0}
\end{eqnarray}
と定義される。これは以下を満たす。
\begin{eqnarray}
  a_i \ket{\vec{\phi}} = \phi_i \ket{\vec{\phi}}, \quad \bra{\vec{\phi}} a_i^\dagger = \bra{\vec{\phi}} \phi_i^* \label{coherent_eigen}
\end{eqnarray}
よってこの状態の上では演算子はc数として振る舞う。


さらに、coherent状態に対する微分やnormについて計算すると
\begin{eqnarray}
  \frac{\p}{\p \phi_i} \ket{\vec{\phi}} = a^{\dagger}_i \ket{\vec{\phi}}, \quad \frac{\p}{\p \phi^*_i} \bra{\vec{\phi}} = \bra{\vec{\phi}} a_i, \quad \braket{\theta}{\phi} = \exp[\sum_i \theta_i^*\phi_i] \label{coh_norm}
\end{eqnarray}
また、このcoherent状態を用いて、今考えている状態空間全体を張ることが出来る。(完全性)
\begin{eqnarray}
  \hat{1} = \int \prod_i \Bigl(\frac{\mathrm{d}\phi_i^*\mathrm{d}\phi_i}{\pi}\Bigr) e^{-\sum_i |\phi_i|^2} \ket{\phi}\bra{\phi}
\end{eqnarray}

\begin{mdframed}[linewidth=1pt]
\textbf{練習問題(1):} 式(\ref{coherent_eigen})を示せ。\\
\textbf{練習問題(2):} 式(\ref{coh_norm})のnormについて示せ。\\
\textbf{練習問題(3):} 完全性について、まず
\begin{eqnarray}
  \hat{1} = \int \prod_i \Bigl(\frac{\mathrm{d}\phi_i^*\mathrm{d}\phi_i}{\pi}\Bigr) f(\{\phi_i, \phi_i^*\}_i) \ket{\phi}\bra{\phi}
\end{eqnarray}
として, $\hat{1}$が満たすべき性質$a \hat{1} = \hat{1}a, \quad a^\dagger \hat{1} = \hat{1}a^\dagger, \quad \bra{0}\hat{1}\ket{0} = 1$から$f(\{\phi_i, \phi_i^*\}_i)$を同定せよ。
\end{mdframed}


\subsection{Fermionのcoherent状態}
さてFermionについても同様にcoherent状態を定義したいが、同じようにc数で使って定義しようとすると、Fermionの反交換関係が反映されない。すなわち$c_i\ket{\phi} = \phi_i\ket{\phi}$とした場合に、$c_ic_j\ket{\phi} = \phi_i\phi_j\ket{\phi} = c_jc_i\ket{\phi}$となり、Fermionの反交換関係($c_ic_j = -c_jc_i$)と不整合である。
よって「反交換関係($\eta_i \eta_j = -\eta_j\eta_i$及び$\eta_i c_j = - c_j\eta_i$)を持つ数」を導入する必要がある。これがGrassmann数である。\footnote{ひょっとすると初めてGrassmann数(もしくはFermion)の交換関係を見た時に、「ベクトルの外積($\vec{A}\times\vec{B} = - \vec{B}\times\vec{A}$)みたいだな」と思った方もいるかもしれない。大正解である。Grassmann数は、ベクトル表現をすることが出来、積として外積(みんなが知っている３次元の外積を少し一般化したもの)の構造を入れたものになっている。ノートの最後に補足を書いておくので、興味がある人はどうぞ。}
経路積分に用いたいので、このGrassmann数の微分と積分を定義する必要がある。これは以下で定義しておくと経路積分で使う際に都合が良い。
\begin{eqnarray}
  \frac{\p}{\p\eta_i} \eta_j = \delta_{ij}, \quad \int d\eta_i 1 = 0, \quad \int d\eta_i \eta_j = \delta_{ij}\label{grass_ana}
\end{eqnarray}
この場合、Grassmann数を変数に持つ滑らかな関数$f(\eta)$の性質として、
\begin{eqnarray}
  f(\eta) = f(0) + \left.\frac{\p f}{\p\eta}\right|_{\eta=0}\eta = f(0) + f'(0)\eta
\end{eqnarray}
のように厳密に書けるという性質がある。反交換関係より$\eta_i^2 = 0$なので、$\eta_i$について1次までで展開できるのだ。特に使うものとして、expの形で
\begin{eqnarray}
  \exp(a \eta) = 1 + a\eta
\end{eqnarray}
となることを覚えておくと良いだろう。($a$はc数。)

さてGrassmann数と微分積分を含めたその演算を定義した。(足し算・引き算は特に定義しなかったが、ベクトルや通常のc数の足し算・引き算と同じように定義する。) これを用いて、Fermionのcoherent状態は、
\begin{eqnarray}
  \ket{\vec{\eta}} = \exp[-\sum_i\eta_i c^{\dagger}_i]\ket{0}
\end{eqnarray}
と定義する。このようにすれば
\begin{eqnarray}
  c_i \ket{\vec{\eta}} = \eta_i \ket{\vec{\eta}}, \quad \frac{\p}{\p\eta_i}\ket{\vec{\eta}} = -c^\dagger_i \ket{\vec{\eta}}
\end{eqnarray}
となる。また$\bar{\eta} = \eta^*$を用いて、
\begin{eqnarray}
  \bra{\vec{\eta}} = \bra{0}\exp[-\sum_i c_i \bar{\eta_i}] = \bra{0}\exp[\sum_i \bar{\eta_i} c_i] 
\end{eqnarray}
とすれば
\begin{eqnarray}
  \bra{\vec{\eta}}c^\dagger_i = \bra{\vec{\eta}} \bar{\eta_i}, \quad \frac{\p}{\p\bar{\eta}}\bra{\vec{\eta}} = \bra{\eta}c_i, \quad \braket{\eta}{\psi} = e^{\bar{\eta}\cdot\psi}
\end{eqnarray}
と書ける。ここで敢えて$\eta^*$と書かずに$\bar{\eta}$と書くのは、これらがGrassmann数の独立な元であることを強調する為であろう。

これらを用いて、Bosonの場合と同様に状態空間全体を張ることが出来る。
\begin{eqnarray}
  \hat{1} = \int \prod_i \Bigl(d\bar{\eta}_i d\eta_i\Bigr) e^{-\sum_i\bar{\eta_i}\eta_i}\ket{\vec{\eta}}\bra{\vec{\eta}}
\end{eqnarray}
\begin{mdframed}[linewidth=1pt]
\textbf{練習問題(4):} Fermionのcoherent状態の内積について確認せよ。\\
\textbf{練習問題(5):} Fermionのcoherent状態の完全性について、Bosonの場合と同様の手続きによって証明せよ。
\end{mdframed}

最後に経路積分で使うのでGrassmann数のGauss積分の公式を導いておこう。
\begin{eqnarray}
  \int d\bar{\eta}\int d\eta e^{-\bar{\eta}a\eta} &=& \int d\bar{\eta}\int d\eta (1 - \bar{\eta}a\eta)\nonumber\\
  &=& a\int d\bar{\eta} \bar{\eta}\int d\eta \eta = a
\end{eqnarray}
2行目から3行目の式変形に$\int d\eta \bar{\eta} = - \bar{\eta} \int d\eta$を用いた。(このようにGrassmann数は積分要素とも反交換関係が生じるので慣れが必要である)

さらに一般化して
\begin{eqnarray}
  \prod_i \Bigl(\int d\bar{\eta}_i \int d\eta_i\Bigr) e^{-\sum_{ij}\bar{\eta_i}A_{ij}\eta_j} = \det(A)
\end{eqnarray}
を得ることが出来る。

[証明]$\prod_{i=1}^n \Bigl(\int d\bar{\eta}_i \int d\eta_i\Bigr)$の積分の結果残るのは$\prod_{i=n}^1\eta_i\bar{\eta}_i$の係数である。$e^{-\sum_{ij}\bar{\eta_i}A_{ij}\eta_j} = \prod_{jk}(1 + \eta_k A_{jk}\bar{\eta}_j)$であるから、今求めたい係数は$j$同士,$k$同士で被らない$A_{jk}$の積の任意の組み合わせの和すなわち$1\sim n$を並べ替えたようなものの任意の並べ替えの和になる。さらにGrassmann数の性質により、$\prod_i\eta_i\bar{\eta}_i$の順番に並び替えようとした際に、並び替え$\sigma$に対して$\mathrm{sgn}(\sigma)$の符号が付くので、結果として
\begin{eqnarray}
  \prod_i \Bigl(\int d\bar{\eta}_i \int d\eta_i\Bigr) e^{-\sum_{ij}\bar{\eta_i}A_{ij}\eta_j} &=& \prod_i \Bigl(\int d\bar{\eta}_i \int d\eta_i\Bigr)\prod_{jk}(1 + \eta_k A_{jk}\bar{\eta}_j)\label{gauss_grass}\\
  &=& \prod_i \Bigl(\int d\bar{\eta}_i \int d\eta_i\Bigr)\sum_{\sigma} \prod_i \eta_\sigma(i) A_{i\sigma(i)} \bar{\eta}_{i}\\
  &=& \sum_{\sigma} \mathrm{sgn}(\sigma) \prod_i A_{i\sigma(i)} = \det(A)\label{grassmann_gauss}
\end{eqnarray}

さらにこのことから、Grassmann数の変数変換をした際の積分要素に出てくるJacobianも計算することが出来る。
というのも、$\vec{\eta'} = A \vec{\eta}$とすると式(\ref{gauss_grass})は
\begin{eqnarray}
  \Bigl(\int d\vec{\bar{\eta}} \int d\vec{\eta}\Bigr) e^{-\vec{\bar{\eta}}^T A \vec{\eta}} &=& \Bigl(\int d\vec{\bar{\eta}'} \int d\vec{\eta'}\Bigr) J^2(A) e^{-\vec{\bar{\eta}'}^TA^{-1} \vec{\eta'}} \\
  &=& J^2(A) \det(A^{-1}) = \det(A)\label{grassmann_jacobian}
\end{eqnarray}
よって$\vec{\eta} \rightarrow\vec{\eta'} = A \vec{\eta}$とする変数変換については$J(A) = \det(A)$となるヤコビアン考える事になる。これは通常の多変数の積分の逆数のファクターがかかる事になっている。これもGrassmann数の特殊性である(式(\ref{grass_ana})から、Grassmann数の積分はある種微分と同じ結果を返すために、むしろ微分としてヤコビアンを考えていると思っても良いかもしれない。)

\begin{mdframed}[linewidth=1pt]
\textbf{練習問題(6):} 上の証明の手順に沿って、n = 2の時($\eta_1, \eta_2$がある時)について、式(\ref{grassmann_gauss})と式(\ref{grassmann_jacobian})を実際に確認してみよ。\\
\textbf{練習問題(7):} 追加のGassmann数$\vec{\bar{\psi}}, \vec{\psi}$(ただし$\vec{\psi} = [\psi_1, \dots, \psi_n]^T$)を導入した時、以下を示せ。
\begin{eqnarray}
  \prod_i \Bigl(\int d\bar{\eta}_i \int d\eta_i\Bigr) \exp[-(\vec{\bar{\eta}}+\vec{\bar{\psi}})^T A (\vec{\eta} + \vec{\psi}) ] = \det(A)
\end{eqnarray}
\textbf{練習問題(8):} 上で証明した事を用いて、
\begin{eqnarray}
  \prod_i \Bigl(\int d\bar{\eta}_i \int d\eta_i\Bigr) \exp[-\vec{\bar{\eta}}^T A \vec{\eta} + \vec{\bar{\eta}}^T\cdot\vec{\psi} + \vec{\bar{\psi}}^T\cdot\vec{\eta}] = \det(A)\exp[\vec{\bar{\psi}}^T A^{-1} \vec{\psi}]\nonumber\\
\end{eqnarray}
となる事を示せ。(左辺の形を見て、「分配関数やモーメント母関数を似てるな」と思った方は良い嗅覚をお持ちである。)
\end{mdframed}

\section{分配関数の経路積分表示}

\subsection{コヒーレント状態によるトレース}
逆温度を$\beta=1/T$（$k_{\mathrm B}=1$）、化学ポテンシャルを$\mu$とし、
$\hat K=\hat H-\mu\hat N$とおく。大分配関数は$\hat{K}$の固有状態$\ket{\boldsymbol n}$($\hat{K}\ket{n} = \xi_n\ket{n}$)を用いて
\begin{equation}
  \Xi=\mathrm{Tr}\Bigl[e^{-\beta\hat K}\Bigr]
   =\sum_{n}\bra{n}e^{-\beta\hat K}\ket{n}
\end{equation}
と書ける。以下ではコヒーレント状態の変数を$\psi,\bar\psi$($\psi$は複数変数(ベクトル)の場合もある)と総称し、$d\bar\psi d\psi$を$d(\bar\psi,\psi)$と略して書く。これらはボゾンの系では複素数であり、フェルミオンの系ではGrassmann数である。
また、ファクター$\zeta$を導入し、ボゾンでは$\zeta=+1$、フェルミオンでは$\zeta=-1$とする。

占有数基底の和にコヒーレント状態の完全性を挿入すると、
\begin{align}
  Z &= \int d(\bar\psi,\psi)\,e^{-\bar\psi\cdot\psi} \sum_{n}\braket{n}{\psi}\bra{\psi}e^{-\beta\hat K}\ket{n} \\
  &= \int d(\bar\psi,\psi)\,e^{-\bar\psi\cdot\psi} \sum_{n}\braket{n}{\psi}\braket{\psi}{n}e^{-\beta\xi_n} \label{25}\\
  &= \int d(\bar\psi,\psi)\,e^{-\bar\psi\cdot\psi} \sum_{n}\braket{\zeta\psi}{n}\braket{n}{\psi}e^{-\beta\xi_n} \label{26}\\
  &= \int d(\bar\psi,\psi)\,e^{-\bar\psi\cdot\psi} \sum_{n}\braket{\zeta\psi}{n}\bra{n}e^{-\beta\hat K}\ket{\psi} \\
  &= \int d(\bar\psi,\psi) e^{-\bar\psi\cdot\psi} \bra{\zeta\psi}e^{-\beta\hat K}\ket{\psi}.
\end{align}
式(\ref{25})から式(\ref{26})の式変形には、状態$\ket{n}$はk個の粒子を含む状態とすると、$\braket{n}{\psi}\braket{\psi}{n} = \zeta^k\braket{\psi}{n}\braket{n}{\psi} = \braket{\zeta\psi}{n}\braket{n}{\psi}$である事を用いた。

\subsection{虚時間の離散化と連続極限}
$\beta$を$N$等分して$\Delta\tau=\beta/N$とし、$e^{-\beta\hat K}$を
$N$個の$e^{-\Delta\tau\hat K}$の積に分解する。隣り合う因子の間に完全性を挿入する。
$\hat K$を正規順序に並べ、その生成・消滅演算子をそれぞれ
$\bar\psi,\psi$に置き換えたものを$K(\bar\psi,\psi)$とすると、
\begin{align}
  Z &= \int d(\bar\psi_0,\psi_0) e^{-\bar\psi_0\cdot\psi_0} \bra{\zeta\psi_0}e^{-\beta\hat K}\ket{\psi_0} \\
  &= \prod_{i=0}^{N-1}\Bigl(\int d(\bar\psi_i,\psi_i) e^{-\bar\psi_i\cdot\psi_i}\Bigr)\bra{\zeta\psi_0}e^{-\tau\hat{K}}\ket{\psi_{N-1}}\dots\bra{\psi_1}e^{-\tau\hat{K}}\ket{\psi_0}
\end{align}
\begin{align}
  \bra{\psi_{j+1}}e^{-\Delta\tau\hat K}\ket{\psi_j}
  =\exp\Bigl[\bar\psi_{j+1}\cdot\psi_j-\Delta\tau K(\bar\psi_{j+1},\psi_j)\Bigr].
\end{align}
便宜上$\phi_N = \zeta\psi_0$とし、各完全性のガウス因子を取り込むと、
\begin{align}
  Z &= \prod_{i=0}^{N-1}\Bigl(\int d(\bar\psi_i,\psi_i) \exp\Bigl[-\Delta\tau\Bigl\{-\frac{\bar{\psi}_{i+1}-\bar{\psi}_i}{\Delta\tau}\psi_i + K(\bar{\psi}_{i+1}, \psi_i) \Bigr\}\Bigr]\Bigr)
\end{align}
$N\rightarrow\infty$の極限では、
\begin{align}
  Z &= \int\mathcal D[\bar\psi,\psi]\,e^{-S[\bar\psi,\psi]},\\
  S[\bar\psi,\psi]
    &= \int_0^\beta d\tau\,\Bigl[
       \bar\psi(\tau)\cdot\partial_\tau\psi(\tau)
       +K(\bar\psi(\tau+\Delta\tau),\psi(\tau))\Bigr].\label{imagtime_action}
\end{align}
ただし虚時間の境界条件として$\psi(\beta)=\zeta\psi(0)$、
$\bar\psi(\beta)=\zeta\bar\psi(0)$である。$N\rightarrow\infty$の極限で$\Delta\tau\rightarrow0$であるが、これが後々重要な役割をするので残しておく。

\subsection{松原振動数と自由系の分配関数}
境界条件に合わせて、虚時間の場を
\begin{align}
  \psi(\tau)&=\frac{1}{\sqrt{\beta}}\sum_{n\in\mathbb Z}\psi_n e^{-i\omega_n\tau},
  &\psi_n&=\frac{1}{\sqrt{\beta}}\int_0^\beta d\tau\,\psi(\tau)e^{i\omega_n\tau},\\
  \bar\psi(\tau)&=\frac{1}{\sqrt{\beta}}\sum_{n\in\mathbb Z}
       \bar\psi_n e^{i\omega_n\tau},
  &\omega_n&=
  \begin{cases}
    2\pi nT & (\text{ボゾン}),\\
    (2n+1)\pi T & (\text{フェルミオン})
  \end{cases}
\end{align}
と展開する。この$\omega_n$を松原振動数と呼ぶ。時刻のずれを残すと、
$\int_0^\beta d\tau\,\bar\psi(\tau+\Delta\tau)\cdot\psi(\tau)
=\sum_n e^{i\omega_n\Delta\tau}\bar\psi_n\cdot\psi_n$となる。一旦相互作用がない事を仮定すると、$K(\bar\psi, \psi) = \bar\psi_a K_{ab}\psi_b$の形で書ける\footnote{indexの$a,b$は略記している$\vec{\psi}(\tau)$の$\psi_a(\tau)$成分という意味である。松原振動数のindex $n$とは異なるので誤解しないように}ので、式(\ref{imagtime_action})に代入すると、
\begin{align}
  S[\bar\psi,\psi] = \sum_n \bar\psi_n (-i\omega_n + Ke^{i\omega_n\Delta\tau}) \psi_n 
\end{align}
ただし$K$は$K_{ab}$の行列表示したものである。

%\begin{comment}
$a$を1粒子Hamiltonianの固有状態のindexとすると、そのエネルギー固有値を$\varepsilon_a$、$\xi_a=\varepsilon_a-\mu$とすると、
$K(\bar\psi, \psi) = \sum_a \xi_a \bar\psi_a\psi_a$であり、作用は
\begin{equation}
  S=\sum_{a,n}\bar\psi_{an}(-i\omega_n+\xi_a)\psi_{an}\label{matsubara_action}
\end{equation}
と対角化される。ボゾンのガウス積分は行列式の逆数を与え、
フェルミオンのガウス積分は式(\ref{grassmann_gauss})の通り行列式を与える。
したがって$Z$は形式的に$\prod_n\det[\beta(-i\omega_n+\xi)]^{-\zeta}$と表せる。
ここで$\beta$が出てきたのは、$\prod_i\int d\bar\psi_i \int d\psi_i$を$\mathcal{D}[\bar\psi, \psi]$にした際に、積分測度をきちんとする必要があったのだ。(一度経路積分形式の導出を終える事を優先したため説明は一旦スキップした。)

つまり元々離散の場合に、離散のFourier変換をしておいて$\sum_i \bar\psi_{i+1}\psi_i \rightarrow \sum_n \bar\psi_{n}\psi_n e^{i\omega_n\Delta\tau}$として、離散版の作用$S_N$は
\begin{align}
  S_N = \sum_{n=1}^N \bar\psi_n(1 - e^{i\omega_n\Delta\tau}(1-\Delta\tau K))\psi_n \quad \rightarrow \quad  \sum_{n=1}^N \Delta\tau\bar\psi_n(-i\omega_n+Ke^{i\omega_n\Delta\tau})\psi_n
\end{align}
これが式(\ref{matsubara_action})と一致するには$\bar\psi' = \sqrt{\Delta\tau}\bar\psi$, $\psi' = \sqrt{\Delta\tau}\psi$として変数変換が必要になる
この際に$\prod_{n=1}^N\int d\bar\psi_n \int d\psi_n = \Bigl(\frac{\beta}{N}\Bigr)^{-\zeta N}\prod_{n=1}^N\int d\bar\psi'_n \int d\psi'_n$となるので、実は$\mathcal{D}[\bar\psi, \psi]$の中には$\mathrm{lim}_{N\rightarrow\infty}(\beta/N)^{-\zeta N}$が含まれており、この$\beta$が出てきていたのだ。

\subsection{練習：粒子数期待値}
この後に出てくるグリーン関数や解析接続の概念の良い例になるので、練習問題として、粒子数期待値を分配関数から計算してみよう。
index $a$の粒子数期待値は、便宜上化学ポテンシャルをindex $a$に依存する形で$\mu_a$と書き、
\begin{align}
  \ev{n_a} &= -\frac{1}{\beta}\left.\frac{\p}{\p\mu_a}\right|_{\mu_a=\mu}\mathrm{ln}Z[\beta, \{\mu_a\}] \\
  &= \prod_n\Bigl(\int\mathcal D[\bar\psi,\psi]\Bigr)\Bigl[\frac{1}{\beta}\int_0^\beta d\tau \bar\psi_a(\tau+\Delta\tau)\psi_a(\tau) e^{-S[\bar\psi, \psi]}\Bigr]/Z\\
  &= \frac{1}{\beta}\int_0^\beta d\tau\ev{\bar\psi_a(\tau+\Delta\tau)\psi_a(\tau)} = \ev{\bar\psi_a(\tau+\Delta\tau)\psi_a(\tau)}\\
  &= \frac{1}{\beta}\sum_n \ev{\bar{\psi}_{n,a}\psi_{n,a}}e^{i\omega_n\Delta\tau}\label{tauGreen}\\
  &= -\frac{\zeta}{\beta}\sum_n\Bigl(\frac{e^{i\omega_n\Delta\tau}}{i\omega_n - Ke^{i\omega_n\Delta\tau}}\Bigr)_{aa}\label{Matsubara_nev}
\end{align}
式(\ref{tauGreen})から式(\ref{Matsubara_nev})について少し説明を追記する。もしも系がボゾンから構成されていれば、
\begin{align}
  \ev{\bar\psi_{n,a}\psi_{n,a}} &= \prod_m(\int \mathcal{D}[\bar\psi_m, \psi_m]) \bar\psi_{n,a}\psi_{n,a} \exp[-\sum_m\bar\psi_m\cdot(-i\omega_m + \tilde{K}\cdot\psi_m]/\Xi\\
  &= -\frac{\p}{\p \tilde{K}_{aa}}\mathrm{ln}\Bigl[\int\mathcal{D}[\bar\psi_n, \psi_n]\exp[-\bar\psi_n\cdot(-i\omega_n + \tilde{K})\cdot\psi_n]\Bigr]\\
  &=-\frac{\p}{\p \tilde{K}_{aa}}\mathrm{ln}\Bigl[\det(-i\omega_n + \tilde{K})^{-\zeta}\Bigr]\\
  &= \Bigl((-i\omega_n + \tilde{K})^{-1}\Bigr)_{aa} = -\zeta\Bigl((i\omega_n - \tilde{K})^{-1}\Bigr)_{aa}\\
  &= -\zeta\Bigl((i\omega_n - Ke^{i\omega_n\Delta\tau})^{-1}\Bigr)_{aa}
\end{align}
